# Steal Book

이미지·영상·링크·임베드·메모를 게시글처럼 담아 두고, 나중에 영감의 원천으로 꺼내 쓰는 개인 아카이브.
PC와 안드로이드 휴대폰에서 같은 내용을 동기화해서 씁니다.

> 처음 설치·배포하는 방법은 **[SETUP.md](./SETUP.md)** 를 보세요.

## 지금 되는 것 (1차)

**담기**
- 화면 어디서든 `Ctrl+V` → 이미지·링크·글이 바로 카드로 담김
- 파일을 창에 끌어다 놓기, 다른 브라우저 탭의 링크·이미지 끌어다 놓기
- 게시글 작성 창: 여러 파일 + 링크/임베드 + 제목 + 메모 + "왜 담았나" + 카테고리 + 태그
- 안드로이드: 유튜브·인스타그램 등에서 **공유 → Steal Book** (앱 설치 후)
- 지원 임베드: 유튜브(쇼츠 포함) · 비메오 · 인스타그램(게시물·릴스) · 틱톡 · X · 스포티파이 · `<iframe>` 코드
- 일반 링크는 제목·대표 이미지·사이트 이름을 자동으로 가져옴
- 이미지 주소(…png, …jpg 등)를 붙여넣으면 **이미지 사본을 저장**해 카드에 바로 보임 (사본을 못 받는 사이트는 원본 주소로 미리보기 + 상세에서 '이미지 사본 저장')
- 이미 담아 둔 링크를 다시 담으면 알려 줌 (추적용 주소 꼬리표는 무시하고 비교)
- 큰 파일 올릴 때 진행률(%) 표시

**보기**
- 벽돌(메이슨리) · 균일 그리드 · 목록 보기, 썸네일 크기 3단계
- 검색(제목·메모·태그·사이트), 종류 · 화면 비율(9:16 ~ 2.39:1) · 색으로 찾기, 태그 필터
- 정렬: 최근 · 오래된 · 제목 · 무작위
- 상세 보기: 크게 보기, ← → 이동, 모바일은 좌우로 밀기
- 상세 닫기: 빈 곳 클릭 · Esc · 휴대폰 뒤로가기 · 아래로 쓸어내리기
- 상세에서 제목·왜 담았나·메모·태그 바로 고치기 (누르면 입력칸, Enter 저장 / Esc 취소)
- 시어터 모드: 지금 목록을 전체 화면 슬라이드로 감상

**영상 작업 특화**
- 영상 카드 위에서 마우스를 움직이면 프리미어 빈처럼 훑어보기 (미리 만든 12프레임 스트립이라 가볍고 빠름)
- 구간 북마크: 재생 중 `I` / `O` 로 구간 표시, 메모, 클릭하면 그 구간 반복 재생
- 유튜브·비메오 임베드도 시작 시각으로 구간 북마크
- "이 장면을 썸네일로": 원하는 프레임을 대표 이미지로

**관리**
- 카테고리 추가 · 이름 · 색 · 이모지 · 순서(끌어서) · 삭제(항목은 인박스로 / 함께 삭제)
- 하위 카테고리(계층): 사이드바 이름 옆 + 또는 관리 창에서 만들기, 상위를 보면 하위 항목까지 함께 보임, 상위를 지우면 하위는 한 단계 위로
- 카드를 사이드바 카테고리로 끌어다 놓아 옮기기
- 여러 개 선택: `Ctrl`+클릭, `Shift`+클릭(범위), `Ctrl+A` / 휴대폰은 길게 누르기 → 한꺼번에 옮기기 · 태그 · 즐겨찾기 · 휴지통
- 모음(스마트 컬렉션): 지금 검색·필터 조건을 이름 붙여 저장 → 조건에 맞는 새 항목이 자동으로 모임
- 휴지통: 지운 항목은 30일 보관 뒤 자동 영구 삭제, 언제든 되돌리기
- 즐겨찾기(편집자가 OK컷에 동그라미 치듯)
- 어둡게(편집실) / 밝게(라이트 테이블) 화면
- 백업 내려받기·불러오기(JSON), 저장 공간 사용량 표시

## 구조

```
StealBook/
├─ api/
│  ├─ unfurl.ts        링크 미리보기 (Vercel 서버리스 함수)
│  └─ keepalive.ts     Supabase 무료 프로젝트 일시정지 방지 (하루 1번 자동 호출)
├─ supabase/schema.sql 데이터베이스·저장소·보안 규칙 (Supabase에 한 번 붙여넣기)
├─ public/             앱 아이콘, manifest(휴대폰 설치·공유), 서비스 워커
└─ src/
   ├─ lib/
   │  ├─ backend/      저장소 교체 지점 (supabase.ts = 동기화, local.ts = 체험 모드)
   │  ├─ capture.ts    담기 처리 (파일 압축·업로드, 링크 미리보기)
   │  ├─ media.ts      이미지 압축, 영상 썸네일·스트립, 대표 색 추출
   │  ├─ embed.ts      유튜브·인스타 등 주소 → 임베드 플레이어
   │  └─ urls.ts       저장소 경로 → 볼 수 있는 주소 (묶어서 받고 재사용)
   ├─ components/      화면 조각 (Gallery, Composer, Detail, Theater …)
   ├─ store.ts         앱 상태와 동작
   └─ App.tsx          레이아웃 · 붙여넣기 · 끌어다 놓기 · 단축키
```

- 화면: React + Vite + TypeScript + Tailwind CSS
- 저장: Supabase (로그인 · Postgres · 파일 저장 · 실시간 동기화)
- 배포: Vercel (화면 + `api/` 함수 2개)
- Supabase 주소/키가 없으면 자동으로 **체험 모드**(이 브라우저에만 저장)로 실행

```bash

npm run build      # 배포용 빌드 확인
```

## 단축키 (PC)

| 키 | 동작 |
|---|---|
| `Ctrl+V` | 어디서든 붙여넣어 바로 담기 |
| `N` | 새로 담기 |
| `/` | 검색 |
| `1` `2` `3` | 벽돌 · 그리드 · 목록 |
| `T` | 시어터 |
| `←` `→` | 상세 보기 이전·다음 |
| `F` / `E` | 즐겨찾기 / 수정 |
| `Ctrl`+클릭 · `Shift`+클릭 · `Ctrl+A` | 여러 개 선택 · 범위 선택 · 보이는 것 모두 |
| `Esc` | 상세 닫기 · 선택 끝내기 |
| `I` / `O` | 영상 구간 시작 / 끝 |
